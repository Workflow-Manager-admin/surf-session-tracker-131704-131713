Build an app called SurfSync

Functionality:
1. Home Screen:
   - Button: “+ Log New Session”
   - List of past surf sessions (each as a card)

2. Log New Session Screen:
   - Date picker (default = today)
   - Text field: Surf spot name
   - Dropdown: Board used (e.g., shortboard, fish, longboard, foamie)
   - Numeric input: Estimated wave count
   - Mood picker: Exmoji or colored slider (e.g., 🟢 great / 🟡 okay / 🔴 poor)
   - Optional notes field (text)
   - Dropdowns or sliders for:
     - Swell size (0–12ft)
     - Wind (Offshore, Onshore, Glassy)
     - Tide (High, Mid, Low)

3. Session Detail View:
   - All entered data in a card layout
   - Option to edit or delete
   - Mood emoji & short notes highlight

4. Stats Dashboard (optional):
   - Simple charts: most visited spot, board usage %, mood trend over time

UI:
- Ocean-themed color palette: soft blues, sandy beige, teal highlights (Oceanic themes, images as backgrounds and icons and hues)
- Icon-based inputs for conditions

Extras:
- Daily reminder to log if surfed today 
- Filter by spot, board, or mood
